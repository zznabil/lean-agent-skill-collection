If root policy is absent, apply the standalone kernel. Do not claim root policy activation without evidence.

## Check source notes before claiming coverage
Each routine links its own SOURCES.md. Nineteen ISO/IEC/IEEE entries lack licensed full text. Their routines explicitly require source access. For series entries, choose the part and edition deliberately. Native HTML, schemas and research papers carry labels that identify their actual type.

## Select by task
Use OpenAPI to describe an HTTP interface. Use AsyncAPI for message-driven operations. Use CloudEvents for the event envelope. These sources are not interchangeable. Use an assurance case to connect a claim with its evidence. Use a quality model to select attributes. Use a review method to inspect a work product.

Use watched, deferred or rejected entries only for their explicit governance or selection question. Do not put them in the ordinary skill search path as universal validators.
