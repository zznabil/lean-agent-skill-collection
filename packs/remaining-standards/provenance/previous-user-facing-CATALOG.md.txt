## Selecting without overloading the agent
Use a task skill to own the work. Select a standards skill for a concrete requirement or review question, not simply because its name is in this pack.
Language: ASD-STE100 for controlled technical English; ISO 24495-1 for plain-language usability; ISO 704 for terminology; BCP 14 for normative wording.
Structure and usable information: Diátaxis for document purpose; 82079-1 for product information; 26514 for software help; 26513 for information review; 23859 for UI text.
Interaction/accessibility: 9241-110 for interaction principles; 9241-210 for the human-centred cycle; 9241-112 for presentation; 9241-171 for software accessibility; 21801-1 and COGA for cognitive barriers; 29138-1 for needs and 29138-4 for applying them; WCAG and APG for web criteria and widget patterns.
Learning: UDL for access options, IES for study design, cognitive-load for segmentation, worked examples for procedural learning, Feynman-style explanation for mechanisms.
Specialised diagnostics: Inclusion Europe Easy-to-Read requires intended-user review. CDC CCI and AHRQ PEMAT remain scoped tools, not global release gates.

Descriptions do not guarantee activation. No host-specific automatic-loading flag, hook or background evaluator is installed. No invocation probabilities are claimed.
