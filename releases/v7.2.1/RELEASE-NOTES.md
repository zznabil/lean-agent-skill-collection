# Lean Agent Skill Collection V7.2.1

V7.2.1 is a publication-hardening release. It does not change any skill content from V7.2.0.

## Changes

- Add an MIT license to the repository and every profile package.
- Include third-party notices in every profile package.
- Add deterministic build tooling for all six profiles and the master archive.
- Expand static validation for metadata, inventories, checksums, ZIP safety, links, placeholders, and common secret patterns.
- Test PowerShell 7 on Linux and Windows PowerShell 5.1 on Windows.
- Add community issue forms, a pull-request template, and citation metadata.
- Clarify AI provenance and distinguish static package validation from runtime host behaviour.

## Integrity

Verify downloaded profile archives with [`CHECKSUMS.sha256`](CHECKSUMS.sha256). The machine-readable archive inventory is in [`RELEASE-MANIFEST.json`](RELEASE-MANIFEST.json).

Choose one profile. Do not install overlapping profiles together.
