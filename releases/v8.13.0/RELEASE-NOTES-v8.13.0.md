## Install and recovery

Choose one profile ZIP and merge its `AGENTS.md` into the trusted project root. Configure the host to load its `skills/` directory. A skills-only installation receives the local kernel fallback in each selected skill, but does not activate the full root action and evidence policy. For optional source packs, install only selected skills after reviewing source access and rights; the local fallback does not grant permission or replace domain safety controls.

To roll back, reinstall the V8.12.0 profile and restore its trusted root policy. Do not mix skills or policies from different releases.

## Evidence boundary

Release artifacts are built from current source and validated for source integrity, package contents, reproducibility, and structural policy coverage. Live host behavior is distinct from static checks; report its separately observed result and any skipped gate in the release record.
