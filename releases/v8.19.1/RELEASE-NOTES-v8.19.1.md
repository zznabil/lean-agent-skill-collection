## Compatibility and limits

The 24 base skills, 27 integrated routines, six profiles and both optional-pack boundaries remain unchanged. All skill bodies and adapter routes are preserved. No runtime dependency or global workflow is added.

Source validation still requires PowerShell 7 or Windows PowerShell 5.1 and Python 3.10 or later. Vale CI continues to use version 3.23.0. Sentence-length warnings remain advisory; this release does not require warning-free prose.

The new checks validate corpus selection and lint behavior. They do not prove live agent skill use, contributor comprehension or formal standards conformance.

## Verification and recovery

Require fresh Vale controls and the full existing release suite on both PowerShell hosts. Require exact merged-main CI before tagging. The attached validation evidence records actual revisions, commands and outcomes.

Use the existing profile and Hermes installation instructions. No migration is required. Keep V8.19.0 and installer backups for recovery. Preserve later persona edits and unrelated user files when reverting an installation.
