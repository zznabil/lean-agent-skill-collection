# Lean Agent Skills V8.2.0 — Explicit Standards & Adaptive Prose

## Summary

V8.2.0 keeps 23 canonical skills and adds no dependency, service, hook, or executable. It makes standards provenance explicit in `AGENTS.md`, `ENGINEERING-CORE.md`, and owning skills while keeping simple user turns short.

## Main changes

- Names ASD-STE100, ISO 24495-1, W3C COGA, Feynman, Diátaxis, and BCP 14 in the global prose contract.
- Uses the lightest structure that improves understanding or action.
- Adds a compact standards source map to `ENGINEERING-CORE.md`.
- Names relevant requirements, quality, test, lifecycle, assurance, architecture, security, accessibility, operations, supply-chain, AI, and data sources beside their actionable rules.
- Restores `docs/STANDARDS-REGISTER.md` for versions, decisions, homes, and review triggers.
- Preserves the considerate-agency, truthful-progress, and one-primary-skill policies.

## Compatibility

This is a nonbreaking content update from V8.1.0. Profile membership and invocation policies are unchanged. Replace the installed profile cleanly or use the matching update-pack directory.

## Limits

The release does not claim formal conformance or certification. Live OMP, Codex, and ChatGPT routing behaviour was not measured in this build environment.
