# V8.23.0 — Action-first Autonomy, Less Ceremony

Release date: 2026-11-21.

## Changes

- Give the agent an outcome, not a workflow to manage. It inspects, decides, acts, verifies and repairs within granted scope.
- Use five flexible phases: Explore → Propose → Apply → Verify/Review → Archive. Routine work goes straight to Apply → Verify. Archive means closeout, not automatic publication or paperwork.
- Make generic plans, ledgers, reports, progress bars and checkpoints conditional on the requested deliverable, continuity, collaboration, risk or required acceptance. Preserve task-specific records and release gates.
- Require extremely concise user-facing prose. Prefer familiar words and useful fragments; sacrifice grammar, not meaning. Preserve requested depth, safety, uncertainty, normative force and exact formats.
- Compact 169 instruction files by 9,924 whitespace-separated words and 42,379 UTF-8 bytes against V8.22.1. These source-size figures do not measure runtime token use or latency.
- Keep engineering-companion loading conditional in all four Hermes installers. Preserve confirmation, collisions, backups, linked-path checks and rollback.
- Strengthen calibrated policy and release-status controls, including contradictions appended to otherwise correct text. Finite checks are not general semantic verification.
- Check requested length, relevant state, scope and intact technical fragments before delivery. Calibrate faithful paraphrases against paired broken answers; keep safety, exact-token and word-count failures blocking.
- Preserve separate permission triggers for external, consequential and surprising work, including standalone use. Clarification-only work loads its selected skill, then uses no further tools. Separately requested verification or action retains its normal permission checks.

The Complete profile retains 24 base skills and 27 supplemental routines. All 134 source skills remain available; both optional packs stay source-only. No new command, runtime, dependency, tool authority or automatic trusted-policy mutation is introduced.

## Installation and upgrade

Download `lean-agent-skills-complete-openai-v8.23.0.zip` with its integrity records. Verify the downloaded digest before extraction. Load `skills/` through the host's skill mechanism and merge `AGENTS.md` through its trusted policy mechanism; discovery alone does not activate policy.

For upgrades, retain the previous package and back up only collection-owned paths and their absence state. Preserve unrelated skills, configuration, credentials, persona text and later edits. Update only the reviewed package-owned files. Restart the host and verify discovery, resource loading and a representative task.

For an isolated Hermes journey, use an explicit disposable `-HermesHome`. Preview first, then install the actual extracted package. Check skills-only, global and project policy as applicable; verify persona preservation, backups, collisions and resource bytes. Start a new host session for discovery and manual `wait-what`. See the [installation guide](../../docs/HERMES-INTEGRATION.md).
