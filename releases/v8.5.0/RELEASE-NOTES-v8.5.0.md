# Lean Agent Skill Collection V8.5.0 — Minimum Sufficient Scrutiny & Momentum

V8.5.0 keeps all 23 canonical skills and all six profiles. It adds no routed skill. The release makes scrutiny proportional to the real risk and evidence gap.

## Modes

```text
DIRECT       Clear local reversible work; one owner; one decisive check.
STANDARD     Bounded multi-file or one-subsystem work; targeted checks.
DEEP         Long-running or consequential cross-boundary work; durable evidence.
ADVERSARIAL  Hidden-defect risk survives normal verification; bounded Gauntlet.
```

## Main changes

- Every extra skill, agent, critic, artifact, check, and review round must close a distinct risk or evidence gap.
- Small work does not create plan files, durable state, delegation trees, critic rounds, broad research, Gauntlet, or routine phase narration by default.
- Implementation follows: unnecessary → existing repository code → standard library → native platform → installed dependency → direct code → new abstraction/dependency only when required.
- The optimization order is correctness → safety → contract/architecture → simplicity → diff size → LOC.
- One current check is sufficient only when it observes the complete claim and can fail honestly.
- Repeated same-class failures trigger a strategy change, not more parameter tweaks.
- `Already exists`, `no change needed`, `ALREADY LEAN`, and `BUILD HARD` are valid evidence-backed outcomes.
- Correctness, security, authorization, data integrity, recovery, accessibility, compatibility, and explicit required behavior are never cut for brevity.

## Research decisions

Selected mechanisms were absorbed from Ponytail, Quickflow, do-it, Small Correct Diff, Scalpel, Just Do It, Plow Ahead, Requirement Zero, Ralph, and GSD Pi. Caveman's extreme prose/context compression and runtime surface were rejected for the stable core. No source runtime, hook, installer, persona, benchmark promise, or commercial surface is bundled.

## Validation

- 48 proportional-rigor scenarios.
- 22-pass static release audit.
- Deterministic double build.
- Validator rejection controls.
- Source and archive validation.
- Repository and scenario-mirror audit.
- PowerShell 7 and Windows PowerShell 5.1 CI.
- Annotated tag, release assets, checksums, and post-publication read-back.

## Evidence limits

Live host routing and task outcomes were not measured. Source-project benchmark numbers use different models and harnesses and are not treated as controlled cross-project evidence. This release does not claim formal standards, security, accessibility, usability, or quality conformance.
