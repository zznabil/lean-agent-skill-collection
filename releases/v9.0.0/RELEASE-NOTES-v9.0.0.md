# V9.0.0 - Smallest Complete Solution

Breaking consolidation from 23 to 17 focused skills. All six profiles remain; Engineering now contains 14, Complete 17, Core 8, Communication 3, Get It Done 5 and Gauntlet 4. Both task packs retain teach, wait-what and writing.

The standing policy and every skill root are shorter. Specific triggers, conditional local references, brief adapters, explicit authority and observable completion replace repeated prose overlays and prescriptive ceremony. Required correctness, safety, validation, error handling, recovery and evidence are not optional brevity trade-offs.

Architecture and requirements discovery move into plan; CLI and conflict resolution into implement; triage into debug; persistent project context into handoff. No retired route aliases remain. Root wrappers and progress bars are conditional rather than universal. Host and user preferences remain applicable within the instruction hierarchy.

Validation compares actual package bytes and exact checksum coverage, retains unsafe-archive controls and adds damaged-source/package tests. The full source manifest excludes only itself among tracked files. Authored V9 scenarios remain explicitly unexecuted model tests.
