# Brand Kit

1. Define audience, promise, personality, category conventions, differentiation, usage contexts, and forbidden signals.
2. Produce two or three materially different identity directions before selecting one.
3. Build the selected system: primary mark, simplified mark, clear space, minimum size, color roles, type pairing, imagery, icon or pattern language, and motion principle when relevant.
4. Test legibility in small, monochrome, light, dark, print, and screen contexts.
5. Show representative applications that reveal whether the system is coherent rather than decorating mockups.
6. Record usage rules and common misuse in one concise board or document.

Do not imitate a living brand closely, claim trademark clearance, or use generated symbols without checking distinctiveness and production fit.
