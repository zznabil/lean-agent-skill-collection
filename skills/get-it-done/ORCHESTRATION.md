# Conditional delegation

Use only when independent work saves enough time or adds enough coverage to pay for briefing, verification and integration. Otherwise use one owner and sequential steps.

Before fan-out, inspect the shared boundary and inventory independently omittable required outcomes. Give each packet a clear goal, anti-scope, owned paths, inputs, dependencies, expected artifact and observing check. Keep the manifest shallow. Every coupled file or shared contract has one writer; use real isolation or serial ownership when overlap cannot be removed.

Use actual host-supported workers. For a parallel claim, launch the independent ready set with distinct handles before waiting on its results. When the host cannot expose safe nonblocking starts, use a labelled sequential fallback. Different labels or CLI names do not prove independent models or execution.

Workers return artifacts and evidence, not approval of the integrated result. Missing handles, null returns, timeouts, stale output and abandoned work stay explicit non-success states. Parent verification observes the current artifact and relevant environment, not merely a checkbox or worker transcript. A returned packet becomes VERIFIED only after that gate and any required manual review pass.

Keep local checks with the owned artifact and cross-packet invariants at integration. Run dependent work as soon as its prerequisites are verified; use a whole-field barrier only for a genuine join, ranking or final judge. Release ownership after verification, not on an unexamined success report.

Default to at most four useful sidecars and reserve budget for integration. If a wave fails through the same shared cause, fix the shared contract or environment before relaunching it. Extend only with verified progress and remaining budget. Report caps, failed workers and unprocessed scope honestly.

Pin and inspect executable workflows and called scripts before running them. A diagram or manifest does not authorise an installer, external service or runtime. This procedure supplies no sandbox or security enforcement.
