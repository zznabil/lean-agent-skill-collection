# Specialist model index

Use one only when its question is distinct from the core sequence.

| Situation | Model | Action |
|---|---|---|
| Several causes fit | Abduction / scientific method | Rank falsifiable causes; run the cheapest separating test. |
| Evidence arrives over time | Bayesian update | Start from a base rate; update confidence by diagnostic evidence. |
| Time or information is limited | Bounded rationality | Set a good-enough threshold and stop when it is met. |
| Claims confuse association with cause | Causal check | Test mechanism, timing, confounders, and reverse causation. |
| Situation is changing quickly | OODA | Observe, orient, act in a reversible way, and learn fast. |
| A metric can be gamed | Goodhart | Pair the proxy with outcome and guardrail measures. |
| System behavior spans parts | Systems / feedback loops | Map boundaries, flows, delays, incentives, and reinforcing or balancing loops. |
| One stage limits throughput | Theory of constraints | Exploit and improve the constraint before non-constraints. |
| Data is noisy | Signal versus noise | Define decision-relevant signal and suppress irrelevant variation. |
| Rough magnitude is enough | Fermi estimate | Decompose, use ranges, and sanity-check orders of magnitude. |
| Multiple actors shape the result | Game theory | Map incentives, information, likely responses, and stable outcomes. |
| User adoption is unclear | Jobs to be done | Define the progress the user seeks and the current alternative. |
| Two requirements conflict | TRIZ | Separate the conflicting states by time, space, condition, or subsystem. |
| Direct testing is costly | Thought experiment | Trace mechanisms and boundary cases, then identify a real test. |
| Shared resource is degrading | Commons | Align incentives, limits, ownership, and feedback. |
| Familiar tools dominate | Maslow’s hammer | Compare at least one option outside the default toolkit. |
| Long-lived dependency choice | Lindy | Prefer proven survival when fit is otherwise comparable. |
| Decision is outside expertise | Circle of competence | Separate known, inferred, and expert-required claims. |
| View may be biased | Debiasing / steel-man | Seek disconfirming evidence and state the strongest opposing case. |
